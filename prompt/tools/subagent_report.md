---
label: 向主 agent 汇报（即时唤醒）
---

主动向发起任务的主 agent 汇报进展 / 结果 / 需要其注意或决策的信息。

**机制**：主 agent **空闲时会立即被唤醒**开新一轮处理你的汇报；主 agent **正在忙**时，你的汇报会作为 steer 注入它当前这一轮，同样能被感知（不会打断它手头的动作）。

**什么时候用**：
- 完成关键步骤、有阶段性结论想同步；
- 遇到需要主 agent 知道 / 决策的问题（例如发现需求歧义、需要额外授权）；
- 子任务较长，想让它尽早知道进展而不是等全部跑完。

**注意**：
- 这是单方向的主动汇报（你 → 主 agent）；主 agent 回复你需通过它后续的来消息 / 插话。
- 汇报要**简洁且自包含**（主 agent 没有你的上下文）：说清「做了什么 + 结论 / 需要什么」。
- 不要每条细节都汇报，避免把主 agent 反复唤醒；关键节点再报。
