---
label: 子代理执行（subagent，异步）
---

把复杂/多步/耗时任务（网页操作、仿真、批量处理、长链分析、生成并运行代码验证等）委派给独立子代理在**后台异步执行**。

说明：
- 调用后**立即返回**一个 `taskId`（不等任务完成）。子代理在后台持续运行。
- 之后可用 `subagent_send`（给该 taskId 插话/补充指令，子代理会感知并调整）与 `subagent_result`（取该 taskId 的状态/结果）。
- 这是"主 agent 与 subagent 多轮对话"：启动 → 过程中可多次插话 → 取结果。
- **多子代理并发请先分清依赖**：无依赖的子任务可并行启动多个；有依赖的子任务必须等前一个 `subagent_result` 到 `done` 拿到结果后，再启动依赖它的下一个。不要盲目并发有依赖的任务。
- 执行环境优先 Windows 侧代理（拥有网页搜索、浏览器、截图、UI 自动化等能力），Windows 不可达时回退本机 Linux 代理。
- 参数 `timeout`（秒）为必须显式指定的超时上限。
