---
label: QQ 跨会话发消息
---

给**别的群聊 / 别的对话**发一条消息（当前对话不需要用它——你的正文会自动发出去，再调它就重复两遍）。

参数：
- message：要发的内容
- target：目标群号或 QQ 号（可写成 `group:<群号>` / `private:<QQ号>`）
- chatType：`group` 或 `private`；省略时按群列表自动判断

只给 message、不给 target 时仍发当前对话，但那属于旧用法，正常回复请直接用正文。

限制：
- 跨会话发送只对管理员开放，其余人调用会被拒
- 目标必须是纯数字的群号/QQ 号；发群时 bot 得在该群里
- 内容里不许出现工具调用 XML，会被直接拒发
