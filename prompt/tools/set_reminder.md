---
label: 设置定时提醒
---

设置一条定时提醒：到点后由系统自动向指定 QQ 会话发消息（不依赖对话是否进行中，bot 重启也会照常发出）。

**使用时机**：用户说"提醒我…""到点提醒""X 点叫我"这类**未来某时刻要做某事**的请求时，**必须**调用本工具真正落库；只在回复里说"我记住了/会提醒你"是无效的（没人会去发）。

## 用法
- `text`（必填）：提醒正文（就是到点要发给用户的那句话，写清楚要做什么）
- `at`（必填，三选一之一）：触发时间。支持 `"2026-09-14 16:00"`（本地时间）、`"+90m"`/`"+2h"`/`"+3d"` 相对时间、ISO 字符串
- `inMinutes`（可选）：相对分钟数，等价于 `at="+Nm"`（与 `at` 二选一）
- `repeatMinutes`（可选）：周期提醒的间隔分钟（如每天 = 1440）
- `until`（可选）：周期提醒的截止时间，格式同 `at`；超过则自动停止
- `chat`（可选）：`private` 私聊（默认）或 `group` 群聊
- `target`（可选）：发送对象 QQ 号/群号；**默认当前会话**，一般不用填

## 规则
- 用户给的若是模糊时间（"明天早上""下周"），先换算成明确时刻，换算依据用当前系统时间；没把握就先把换算结果说给用户确认
- 周期性提醒务必用 `repeatMinutes`+`until` 表达，不要一次性加几十条
- 设置完把**实际触发时间和内容**回给用户（例如"已设置：9-14 12:00 提醒你选课截止"）
- 用户要改时间 → 先 `list_reminders` 找到 id，`cancel_reminder` 删掉再重设（或直接新建一条）
