# save_memory —— 永久记住某件事

当场把一条信息写入长期记忆（仅在你明确要"记住/永久记住/以后都要记得"时使用；不要为每条对话都记，避免记忆膨胀）。

## 用法
- `content`（必填）：要记住的内容，一句话说清
- `type`（可选）：`fact` 事实 / `pref` 偏好 / `promise` 承诺 / `event` 事件，默认 `fact`
- `global`（可选，仅管理员）：设为全局常驻记忆（每次会话都会注入，适用于"永远不变的重要规则/系统信息"）

## 语义
- 写入即 `pinned`（不参与 LRU 淘汰，永久保留）；`global` 写入全局常驻表（无自动清除）
- 来源自动按当前会话隔离：私聊记给该用户、群聊记给该群
- 与自动收割（harvest 提取的事实）互不影响，同内容会合并（向量相似 >0.92 视为同一条并刷新时间）

## 规则
- 只记**确定需要长期记住**的信息；临时信息用正常回复即可
- 一句话、客观、可独立理解（不要带"我说过"这类上下文依赖）
